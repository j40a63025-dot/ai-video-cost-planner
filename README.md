# AI Video Cost Planner

Free calculators and guides to estimate the cost of AI video generation (Veo, Kling, Runway, Luma, Pika, Sora, Higgsfield). English at `/`, Spanish at `/es`.

Stack: Next.js (App Router, SSG), Tailwind v4, TypeScript. Prices live in `data/pricing.json`.

## Env vars
- `NEXT_PUBLIC_SITE_URL`
- `RESEND_API_KEY`, `NOTIFY_EMAIL`, `NOTIFY_FROM` (optional) — waitlist/contact emails

## Dev
```
npm install
npm run dev
```
